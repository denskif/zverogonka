# Супергонка / Суперперегони

Простая игра для ребёнка от четырёх лет: посчитать 1–10 дорожных конусов и выбрать цифру. Человек-паук бежит наперегонки с Халком и Локи по движущейся трассе. При ошибке соперники обгоняют его. Пять раундов без таймера, рекламы, аккаунтов и сбора данных. Иллюстрации героев нарисованы для этого проекта.

## Локальный запуск

Нужен Node.js 24. Из папки проекта:

```sh
node --test tests/*.test.mjs
node scripts/build.mjs
node scripts/serve.mjs
```

Открыть адрес, который напечатает сервер. На iPad для установки нужен опубликованный HTTPS-адрес.

## Как устроен рабочий цикл

1. Каждое изменение делаем в отдельной ветке и сохраняем коммитом.
2. Pull request запускает автоматические тесты и сборку. Артефакт `game-build` можно скачать и проверить.
3. После слияния с `main` те же проверки проходят снова, затем GitHub Pages публикует игру.
4. На iPad открыть опубликованный адрес в Safari → «Поделиться» → «На экран Домой» → «Добавить». В новых версиях iPadOS доступен переключатель «Открывать как веб-приложение».
5. Изменения на `main` публикуются по тому же адресу. Версию меняем в `VERSION` по схеме major.minor.patch и ставим Git-тег `v0.1.0` для первого выпуска.

В настройках репозитория GitHub → Settings → Pages → Build and deployment → Source нужно выбрать **GitHub Actions**. Для первой публикации понадобится подключить репозиторий к GitHub; локальный проект уже готов к этому.

## Проверка на iPad

Проверить портретную и горизонтальную ориентацию, звук, переключение языка, счёт до десяти, пять раундов, правильный ответ, ошибку, обгон соперников, фейерверк при победе, повтор игры, запуск с экрана «Домой».

## Дальше

Следующие выпуски могут добавить животных, другие предметы для счёта и уровни сложности. Путь в App Store потребует отдельной нативной сборки, подписи и тестирования через TestFlight; к этому вернёмся после проверки первой версии на iPad.
