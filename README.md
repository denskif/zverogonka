# Играй и учись / Грай і навчайся

Игра для ребёнка от четырёх лет с двумя режимами:

- **Гонки:** посчитать 1–10 дорожных конусов и помочь Человеку-пауку обогнать Халка и Локи.
- **Учить слова:** выбрать существительные, глаголы или тестовый набор, услышать болгарское слово и выбрать одну из четырёх картинок. Пять разных слов за игру, победа при 4 или 5 верных ответах.

В обоих режимах пять раундов без таймера, рекламы, аккаунтов и сбора данных. В языковом режиме слово не показывается текстом: iPad произносит его сразу и ещё раз через три секунды; кнопка позволяет послушать снова. Озвучивание использует голос устройства, поэтому на iPad должен быть доступен болгарский голос.

В игре 100 существительных и 100 глаголов с отдельными картинками и сценками действий. Большинство существительных и основные глаголы сверены с [учебным словарём Caritas Sofia уровня A1](https://caritas.bg/cms/wp-content/uploads/2019/01/A1-English_2nd-edtition.pdf); знакомые ребёнку названия животных дополнены по [учебным материалам Регионального центра Софии](https://rcsf.bg/wp-content/uploads/2024/03/uchpomagalo_1-4_rcpppo_11052021.pdf). Остальные глаголы — простые действия из повседневной жизни ребёнка.

Раздел «Тест» содержит 12 пробных SVG-иллюстраций действий. Это отдельная подборка для оценки нового стиля картинок; существующие карточки глаголов пока не меняются. Исходник иллюстраций — `scripts/create-test-scenes.mjs`, готовые файлы — `assets/test-scenes/`.

## Локальный запуск

Нужен Node.js 24. Из папки проекта:

```sh
node --test tests/*.test.mjs
node scripts/build.mjs
node scripts/serve.mjs
```

Открыть адрес, который напечатает сервер. На iPad для установки нужен опубликованный HTTPS-адрес.

## Как устроен рабочий цикл

1. Изменения сохраняем коммитом и присваиваем выпуску номер в `VERSION` и Git-тег.
2. Pull request, если работаем через отдельную ветку, запускает автоматические тесты и сборку. Артефакт `game-build` можно скачать и проверить.
3. После отправки изменений в `main` проверки проходят снова, затем GitHub Pages публикует игру.
4. На iPad открыть опубликованный адрес в Safari → «Поделиться» → «На экран Домой» → «Добавить». В новых версиях iPadOS доступен переключатель «Открывать как веб-приложение».
5. Изменения на `main` публикуются по тому же адресу. Версию меняем в `VERSION` по схеме major.minor.patch и ставим соответствующий Git-тег.

В настройках репозитория GitHub → Settings → Pages → Build and deployment → Source нужно выбрать **GitHub Actions**. Для первой публикации понадобится подключить репозиторий к GitHub; локальный проект уже готов к этому.

## Проверка на iPad

Проверить портретную и горизонтальную ориентацию, оба пункта главного меню, выбор существительных и глаголов, переключение русского и украинского интерфейса, гонку, четыре картинки на раунд, два воспроизведения болгарского слова с интервалом три секунды, кнопку повтора, победу при 4/5, проигрыш при 3/5, фейерверк, повтор игры и запуск с экрана «Домой».
